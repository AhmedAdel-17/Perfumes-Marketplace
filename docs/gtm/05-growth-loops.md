# Growth loops

Loops, not funnels: each output feeds an input. Each loop names its fuel, its friction, the
data that proves it is turning, and the phase it is allowed to run in.

| Loop | Fuel | Mechanism | Friction | Proof | Phase |
|---|---|---|---|---|---|
| **House-audience loop** | a house's followers | bio link → storefront → order → SMS with tracking → review → reorder link | link not in bio; storefront looks generic | storefront_referral orders; direct return | pilot |
| **Cross-house loop** | a buyer who trusted one house | "from other houses" rails, family browsing, compare, one bag | thin shelf; identical bottles | multi-house baskets; cross-brand purchase | pilot → 2 |
| **Review loop** | delivered orders | review request at +7 days → six-dimension review → rating on tile → conversion | no message; forgery risk | reviews per earned; conversion by rated vs unrated | pilot → 2 |
| **Seller-proof loop** | attributed marketplace orders | statement shows an order the house did not bring → house refers a house → supply deepens | attribution inert | referrals per house; S2 inbound | pilot → 2 |
| **Content/SEO loop** | house stories, education | pages rank for Arabic queries → organic arrivals → orders → more houses to write about | content capacity | organic_search orders | 2 |
| **Creator loop** | creators with codes | disclosed code → order → performance pay → more creators | disclosure and fraud rules | creator_affiliate orders; CAC | 2 |
| **CRM loop** | opted-in customers | new arrivals from bought houses; reorder; review ask | consent, message cost | email_crm orders; opt-out rate | 2 |
| **Referral loop** | happy customers | share page → friend buys → documented benefit | mechanics | referral_complete | 2 |
| **Data loop** | orders, reviews, notes | better bands, better search, better compare → conversion | notes dictionary absent | conversion by stage over time | 2–3 |

## Loop governance

- No loop runs on subsidy it cannot account for (doc 03 §10).
- Every loop's fuel is an attribution touch or a transition — it must appear in
  `/ops/insights` or it is not a loop, it is a hope.
- Loops that borrow demand (house-audience) are measured for what they *own* afterwards
  (direct return, cross-brand) — doc 01 §9.
