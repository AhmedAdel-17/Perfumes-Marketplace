Redesign directions — home page

Four directions for the same screen and the same content. Each has its own Arabic + Latin type pairing, its own palette and its own layout. Every sample is Arabic-first (RTL) with a working English switch in its header, and is built to work at phone, tablet and desktop widths. Pick one, and it becomes the design system for every screen.
